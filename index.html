02 / ENTENDA O CÓDIGO

Dois caminhos. Um objetivo.

Ambos colocam os mesmos números em ordem, mas com estratégias diferentes.

⇅
ALGORITMO 01

Bubble Sort

Percorre a lista comparando vizinhos. Quando um par está fora de ordem, faz a troca. A cada passagem, um dos valores chega à sua posição final.

PIOR CASO O(n²)MELHOR CASO O(n)
↳
ALGORITMO 02

Insertion Sort

Constrói uma parte ordenada da lista, inserindo cada novo número no lugar certo. Esta versão usa trocas entre vizinhos para tornar os movimentos visíveis.

PIOR CASO O(n²)MELHOR CASO O(n)

Os métodos são implementados manualmente em JavaScript, sem usar Array.sort() para realizar a ordenação.
